仿真基础工具C++17 / Python

SPICEUnion

用一套流程，完成仿真执行与结果读取。

将参数化仿真任务交给 Spectre 或 ngspice 并发执行，再读取结构化结果。面向参数扫描与电路设计探索，支持按输入顺序返回结果，并隔离单个任务的失败。

了解 SPICEUnion↗ 中文使用指南↗

仿真工作流程

  1. 01
    定义仿真任务网表与参数值
  2. 02
    执行仿真Spectre / ngspice
  3. 03
    读取结果直流、交流与瞬态数据

可从 Python 调用，也可嵌入 C++ 项目。运行仿真需要自行安装对应的仿真器。

并发执行C++17

OrderedConcurrentPool

一个轻量的 C++17 纯头文件工作池，支持批量任务并发执行，并按输入顺序返回结果。它也是 SPICEUnion 使用的并发执行组件。
