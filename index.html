Primary project

SPICEUnion: a reusable execution layer for simulation-heavy analog EDA workflows.

Circuit optimization, sizing, and verification loops often need hundreds or thousands of simulations. SPICEUnion packages the loop as an embeddable library: submit parameterized cases, run real simulators concurrently, isolate failures, and read results through one structured model.

Open SPICEUnion Execution pool dependency
Execution Spectre / Ngspice backends, ordered batch execution, per-task isolation.
Results Scalar, DC sweep, AC response, transient waveform, PSFASCII and ngspice parsing.
Interfaces C++17 public API, optional pybind11 bindings, packaging-oriented repository layout.
Engineering CI, simulator discovery, diagnostics, and no proprietary PDK bundled by default.
