Simulation infrastructureC++17 / Python

SPICEUnion

One workflow for running simulations and reading results.

Submit parameterized cases to Spectre or ngspice, run them concurrently, and read structured results. Built for parameter sweeps and circuit design exploration, with ordered results and per-task failure isolation.

Explore SPICEUnion ↗ Usage guide (中文) ↗

The simulation workflow

  1. 01
    Define casesNetlist + parameter values
  2. 02
    Run simulationsSpectre / ngspice
  3. 03
    Read resultsDC, AC & transient data

Use from Python or embed in C++. Running simulations requires your own simulator installation.
