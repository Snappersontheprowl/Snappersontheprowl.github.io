# Assets

This directory contains browser-served static assets for the GitHub Pages site.

## Layout

- `css/`: site-wide stylesheets.
- `js/`: small progressive-enhancement scripts.
- `images/`: local images, screenshots, and exported visual assets.

## Naming Rules

- Use stable semantic names such as `site.css`, `site.js`, or `project-card.png`.
- Use lowercase kebab-case for new asset filenames.
- Avoid stage words such as `new`, `final`, `tmp`, `test2`, and `v2`.
- Keep generated or heavyweight source files outside this directory unless they are meant to be served by GitHub Pages.
